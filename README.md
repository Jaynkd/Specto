# Specto
Specto is a next-generation hardware telemetry and benchmarking desktop application designed to stress-test laptops and visualize system performance in real time.

Key Feature Highlight

    ⚡ Zero-bloat Architecture: Low idle resource footprint powered by Rust native system calls (sysinfo).

    🔥 Multi-Core CPU Stress Engine: High-concurrency math workloads using Rayon parallel iterators.

    🎮 WebGL GPU Stress Viewport: Dynamic shader rendering loop to test frame stability and thermal throttling under load.

    📊 Live Telemetry Stream: Real-time monitoring of CPU load, GPU frame rates, memory utilization, and hardware indexes.

    🎨 Modern UI/UX: Built with Tailwind CSS, Framer Motion, and shadcn/ui visual cues.
